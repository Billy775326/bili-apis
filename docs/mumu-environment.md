## 待明确授权的变更

拟仅对 MuMu 1 将 `root_permission` 从 `false` 改为 `true`，并重启一次，为后续临时调试服务提供所需权限。此设置会持续启用模拟器内的高权限访问，需用户明确选择；Root 本身也不保证 ARM64 转译进程可被工具完整观测。

自动审批已拒绝该变更，理由是用户授权了环境搭建和匿名验证，但尚未明确授权持久改变模拟器安全设置，且仍有较低权限的检查方式。因此当前未执行 Root 配置或重启，继续完成了匿名界面观察和主机工具安装。批准后才推进该项；若保持关闭，则继续采用现有权限可完成的验证方式，并保留请求映射的覆盖限制。
